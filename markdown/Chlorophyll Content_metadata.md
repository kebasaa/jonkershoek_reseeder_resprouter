# Metadata for Chlorophyll Content.xlsx

Chlorophyll content measurements by barcode.

## Columns

Physical units, formats, or value types are provided where they can be assigned from the instrument documentation, Eddy Covariance conventions, column names, or project processing context.

| Column | Unit | Description |
| --- | --- | --- |
| `Barcode` | identifier | Leaf/sample barcode used to link chlorophyll measurements. |
| `Chl[mg/m^2]` | mg m^-2 | Chlorophyll content, in mg m^-2. |
| `CFR` | dimensionless ratio | Chlorophyll fluorescence ratio reported with the chlorophyll measurement. |
