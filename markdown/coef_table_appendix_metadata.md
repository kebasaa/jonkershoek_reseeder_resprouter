# Metadata for coef_table_appendix.csv

Appendix coefficient table linking stomatal conductance and electron transport rate relationships by species or plant type and leaf age.

## Columns

Physical units, formats, or value types are provided where they can be assigned from the instrument documentation, Eddy Covariance conventions, column names, or project processing context.

| Column | Unit | Description |
| --- | --- | --- |
| `species` | category | Plant type: Nit-A is Protea nitida adult, Nit-S is Protea nitida seedling, and Rep-S is Protea repens seedling. |
| `leaf_age` | category | Leaf cohort, defined as Yng, Mid, or Old. |
| `intercept` | model response units | Regression intercept. |
| `coef_ETR` | model coefficient units | Regression coefficient for electron transport rate. |
| `coef_gs` | model coefficient units | Regression coefficient for stomatal conductance. |
| `R2` | dimensionless statistic | Coefficient of determination. |
| `p` | probability | Model or coefficient p-value. |
